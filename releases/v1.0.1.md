# AqarDesk Desktop v1.0.1

## Summary

This update fixes desktop window controls and moves signed automatic updates
to the public Cloudflare R2 endpoint, allowing the source repository to remain
private.

## Added

- publish signed updates to shared R2 bucket (release)

## Fixed

- update application icon files for improved visuals (icons)
- add 'core:window:allow-close' permission to default capabilities (permissions)
- configure Mulverse licensing in production builds (release)
- stage bundles from workspace target (release)
- pass updater public key in Tauri format (release)
- compile paraglide before type checking (web)

## Known Issues
Existing v1.0.0 installations must install this update manually once because
they still check the private GitHub release endpoint.
