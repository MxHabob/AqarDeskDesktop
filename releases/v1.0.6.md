# AqarDesk Desktop v1.0.6

## Summary

New contracts now use the saved DocForge template design, keeping their PDF
layout aligned with the editor. Each contract retains a snapshot of its design
and data context.

- Use the saved DocForge layout when creating and previewing contracts.
- Omit images without a source so missing logos do not affect PDF layout.
