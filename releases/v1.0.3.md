# AqarDesk Desktop v1.0.3

## Summary

Create polished rental contracts and payment receipts with a more capable
document editor, multi-page support, and A5 receipt layouts.

## Added

- Preview contract documents and payment receipts as PDFs.
- Create, issue, amend, and end contracts.
- Design contract documents with configurable page and branding settings.
- Use A5 paper for payment receipt templates.
- Browse larger property, tenant, owner, user, and payment lists more smoothly.
- Identify properties with automatically generated property codes.

## Improved

- Move and select template elements across pages in the document editor.
- Refine payment and settings lists with additional fields.
- Improve payment forms and currency selection.
- Improve property and loading views.

## Known Issues

None currently known.
