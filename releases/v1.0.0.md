# AqarDesk Desktop v1.0.0

## Summary

The first stable AqarDesk Desktop release brings property and tenant management,
lease and contract workflows, and payment tools together in one desktop app.

## Highlights

- Manage properties and tenants, create reusable lease and contract templates,
  and track payments with receipt and multi-currency support.
- Get started with default lease templates and use built-in user and licensing
  management.
- Work in Arabic or English with right-to-left and left-to-right interface
  support, plus improved accessibility and notifications.

## Available Builds

- Windows x64
- macOS Apple Silicon

## Known Issues

None currently known.
